# Fonts

`fraunces-latin-var.woff2` is the latin subset of [Fraunces](https://fonts.google.com/specimen/Fraunces)
as a variable font, covering weights 400-700 in one 67kB file.

Fraunces is licensed under the SIL Open Font License 1.1, which permits
redistribution and embedding: https://openfontlicense.org

It is vendored rather than fetched from a font CDN so the page has no
third-party request on the critical path.
